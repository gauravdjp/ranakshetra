ABOUT PROJECT [PHASE - 1]:
A PLATFORM THAT MANAGES TOURNAMENTS, KEEP RECORDS OF PLAYERS PERFORMANCE, HANDLE CLUBS. THE PLATFORM HOST 3 TYPES OF TOURNAMENTS, PRIVATE, PUBLIC AND CLUB TOURNAMENTS. CURRENTLY IN PHASE-1 OF APPLICATION THE PLATFORM WILL SUPPORT ABOUT 20 TOP COMPETITIVE GAMES. GIVING A FULL SUPPORT OF GAMES API TO MAKE THE TOURNAMENTS MORE ENGAGING AND INTERACTIVE. PROVIDING TRUSTABLE AND EFFICIENT RATING SYSTEM. (GLOBAL, CONTINENT, COUNTRY, STATE, CITY, CLUB OR COLLEGE).
